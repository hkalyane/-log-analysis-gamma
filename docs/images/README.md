# Marketplace Images

This directory contains visual assets for the VS Code Marketplace listing.

## Image Guidelines for VS Code Marketplace

1. **Main Icon**: 128x128px PNG (already in package.json)
2. **Screenshots**: 1200x800px or 16:9 ratio recommended
3. **Feature Highlights**: Clear, high-contrast images
4. **Interface Examples**: Show actual VS Code interface

## Current Assets

- performance-comparison.png - Shows before/after performance metrics
- interface-overview.png - Main extension interface
- team-collaboration.png - Unified settings workflow
- filter-management.png - Filter creation and management
- focus-mode.png - Focus mode demonstration

These images will be referenced in the marketplace description to showcase key features visually.
